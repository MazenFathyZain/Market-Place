# متجر علم — سوق الكتب والنوادر

تطبيق سوق عربي للكتب والجرائد والمجلات والمخطوطات والكتب القديمة. مبني بـ React وVite للواجهة، وNode.js وExpress للـAPI، وSQLite للبيانات. يستخدم migrations مرقمة وSwagger UI لتوثيق الـAPI.

## التشغيل المحلي

المتطلبات: Node.js 22 أو أحدث وnpm.

```bash
npm install
cp server/.env.example server/.env
# عدّل JWT_SECRET في server/.env
npm run migrate
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='a-long-private-password' npm run seed:admin
npm run dev
```

افتح الواجهة على <http://localhost:5188>، وSwagger على <http://localhost:4000/api/docs>. إذا أردت بيانات تجريبية في الكتالوج:

```bash
ADMIN_EMAIL=you@example.com npm run seed:demo
```

البيانات التجريبية للعرض فقط؛ احذفها أو استبدلها بكتبك الحقيقية قبل إطلاق السوق.

## سير العمل

1. ينشئ العميل حساباً للشراء أو حساب بائع. ويمكنه تفعيل البيع لاحقاً من حساب الشراء نفسه. ومن صفحة **حسابي** يستطيع تحديث الاسم والبريد والهاتف والعنوان واسم المتجر وكلمة المرور.
2. يضيف البائع معروضاً وصورة؛ حالته الأولية `pending` ولا يظهر في الكتالوج.
3. يراجع المدير المعروض من لوحة الإدارة ويوافق عليه أو يرفضه مع ملاحظة.
4. تعديل البائع لمعروض منشور يعيده إلى `pending` حتى يُراجع مرة أخرى. معروضات مالك المتجر وتعديلاته تُنشر فوراً دون موافقة إضافية.
5. يختار العميل المواد ويؤكد الطلب ببيانات التوصيل. إذا كانت السلة من عدة متاجر، يُنشأ طلب مستقل لكل متجر بإجمالي وحالة منفصلين. تظهر رسالة عند محاولة تجاوز الكمية المتاحة. تُحجز الكمية فوراً، وطريقة الدفع في هذه النسخة **عند الاستلام**. يمكن للمدير متابعة الطلبات مجمعة حسب المتجر؛ الإلغاء يعيد الكمية للمخزون.

سجلات العروض القديمة محفوظة في قاعدة البيانات للأرشفة فقط؛ لا توجد واجهة أو API لمزادات جديدة. المعروضات السابقة متاحة للبيع العادي بسعرها المسجل.

## الأوامر

- `npm run dev`: تشغيل الواجهة والـAPI معاً.
- `npm run build`: بناء الواجهة في `client/dist`.
- `npm run migrate`: تطبيق migrations الجديدة فقط.
- `npm test`: اختبارات الـAPI.
- `npm run seed:admin`: إنشاء أو تحديث حساب المدير من متغيرات البيئة.
- `npm run seed:demo`: إضافة بيانات عرض تجريبية.

## API

التوثيق التفاعلي: `/api/docs`. ملف OpenAPI الخام: `/api/openapi.json`. يستخدم JWT في `Authorization: Bearer <token>` للمسارات المحمية. السعر رقم صحيح **بالجنيه المصري**. الصور المرفوعة تحفظ محلياً في `server/uploads`؛ قاعدة البيانات في `server/data`، وكلاهما خارج التتبع.

## قبل النشر الفعلي

اضبط `JWT_SECRET` عشوائياً وطويلاً و`CLIENT_ORIGIN` على نطاق الواجهة. وفّر نسخاً احتياطية لقاعدة البيانات وملفات الصور، وانقل الصور إلى تخزين دائم إذا شغّلت عدة نسخ من الخادم. الدفع الإلكتروني، الشحن الآلي، إشعارات البريد، والعمولات غير مدمجة في هذه النسخة.
